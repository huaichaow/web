# Blizzard Entertainment assets: not for redistribution

The files in this folder are converted from Warcraft III game files (War3.mpq, War3x.mpq, War3xLocal.mpq) and
from a DotA Allstars map (C1C1807E7D6FA77FC9A5B6E8B8A48868.w3x), owned by Blizzard Entertainment, Inc. and the map's authors.
They were converted by `npm run war3` (tools/war3/) for an unlicensed trial of this project. They are not covered
by the project's license, are never committed, and must not be published or redistributed. Licensing is handled
separately by the owner; without these files the game draws its primitive shapes.

Built 2026-10-20. Rebuilding from scratch: WAR3_PLAN.md, "Rebuilding the War3 pack".
